# ForceFocus 分阶段无障碍诊断

把整个 accessibility-diagnostics 文件夹放进 platform-tools（adb.exe 所在目录），连接手机，双击 start.bat。按中文提示操作手机，完成后上传生成的 ForceFocus-diagnostics-日期时间.zip。不需要录屏、手动筛日志或判断原因。

采集两种开启路径、快捷按钮配置、权限时间线、设置记录的写入包名、绑定状态、进程退出信息以及 all logcat 缓冲区。设置写入元数据是最后记录的写入方，不一定是实际发起策略的组件；正式系统可能缺少历史记录。权限轮询存在采样间隔，不保证捕获每一个短暂变化。每阶段与捕获到的权限变化都有快照。

前三步在未专注时测试：系统页面开启；快捷悬浮按钮开启；打开微信。只有确认安装 0.3.3 且微信切换后服务仍在系统启用名单，才提示专注切换测试，否则自动跳过。普通诊断不启停权限、组件，不清空手机日志，不删除数据，只终止自己启动的电脑 logcat 进程。

紧急退出：单独双击 emergency-stop.bat，可停用 ForceFocus 无障碍组件，不删除数据。解除停用：需要时双击 restore-component.bat，然后在手机系统设置自行开启服务。恢复组件不等于已授予无障碍权限。只在需要退出或恢复时运行这两个辅助文件。

日志留在本地并交给用户上传，不写入公开 GitHub。代码检查已完成，本环境没有 Windows PowerShell 和连接的手机，实际运行与权限稳定性仍需用户设备验证。冻结前端和 APK 未改。
